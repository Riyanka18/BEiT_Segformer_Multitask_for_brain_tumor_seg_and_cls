# Multi-Task Brain Tumor Analysis using BEiT + SegFormer + CBAM with Explainable AI

An explainable deep learning framework for simultaneous brain tumor classification and segmentation from MRI images using a shared BEiT transformer encoder and an attention-enhanced SegFormer decoder with CBAM attention and deep supervision.

The proposed architecture performs:
1. Multi-class brain tumor classification
2. Tumor segmentation
3. Explainable AI visualization using Eigen-CAM
within a unified multi-task learning framework.
